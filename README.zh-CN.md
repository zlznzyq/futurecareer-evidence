# FutureCareer Evidence

> **用公开数据，把AI时代的职业选择讲清楚。**

当前覆盖 **867个美国SOC6职业**。

> **重要：当前底层主要是美国职业数据。** 对中国用户而言，它是职业结构、AI变化和国际趋势参考，不代表中国本地工资、招聘数量或就业增长。

用户可以：

**看懂职业 → 比较职业 → 按自己的偏好重算 → 收藏 → 后续跟踪**

核心原则：

- AI暴露 ≠ 被替代概率
- 事实 ≠ 比较分 ≠ 研究推断
- 每个公开数字必须有来源和公式
- SOC2历史大类不能冒充SOC6具体职业历史
- 缺失值不静默填0

## 核心功能

- Career Snapshot
- CEI Beta
- 最多3职业Compare
- Personal Fit限时开放体验
- 收藏与Watch预览
- 每个指标的“为什么？公式和来源”
- 完整Methodology与GitHub复现
