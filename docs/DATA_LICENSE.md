# Data and License Notes

FutureCareer code is released under the repository software license.

Third-party data is **not relicensed** by FutureCareer.

Upstream sources include:

- O*NET
- U.S. Bureau of Labor Statistics
- International Labour Organization
- Anthropic Economic Index
- World Economic Forum

Before redistributing raw upstream files, check the original source terms.

The public repository should prefer:

- derived metrics;
- source identifiers;
- transformation code;
- links to upstream sources;

when redistribution rights are uncertain.
