# 中国用户首轮测试：数据边界

FutureCareer v1.0 的职业底层数据主要来自美国。

## 当前可以回答

- 美国职业的 BLS 就业、工资和岗位预测；
- 美国 O*NET 职业任务与工作结构；
- 映射后的 ILO GenAI 潜在暴露；
- Anthropic Economic Index 观察到的 AI 使用；
- WEF 2025 未来技能方向与 BLS 技能的 Beta 对齐；
- RPLS 的美国 SOC2 历史劳动力市场背景。

## 当前不能直接回答

- 中国某职业的真实工资；
- 中国校招岗位数量；
- 中国城市之间的岗位机会；
- 中国职业分类下的准确就业增长；
- “在中国选择这个职业的成功概率”。

## 面向中国用户怎么用

把当前版本理解为：

> **美国公开职业数据提供的结构化参考和比较基准。**

它适合帮助用户理解职业结构、AI变化和国际职业趋势，但不应把美国工资/就业数字直接当作中国本地结论。

未来中国版必须单独接入中国职业分类、招聘、工资和教育数据，而不是简单换算美元。
