# User Research Plan — v0.8

Test whether users can:
1. explain what a 0–100 score means;
2. compare two occupations without instruction;
3. understand a career within 10 seconds using Career Snapshot;
4. change Personal Fit weights meaningfully;
5. save careers they intend to revisit.

Future privacy-respecting events: `search`, `career_open`, `compare_add`, `compare_open`, `evidence_open`, `fit_open`, `fit_weight_change`, `career_save`.

Do not collect sensitive personal attributes in v0.8.
