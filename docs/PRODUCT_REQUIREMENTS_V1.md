# Product Requirements v1.0

## North star
Help a user understand, compare, personalize and revisit a career decision.

## Core loop
Discover → Snapshot → Evidence → Compare → Personal Fit → Save → Return.

## Launch features
- 867-career search
- deep-linkable career pages
- Career Snapshot
- CEI Beta
- raw evidence + percentile interpretation
- formula/source evidence cards
- 3-career compare
- Personal Fit Open Beta
- local Save/Watch
- update center
- share career / compare links
- methodology page
- GitHub feedback entry

## Deliberately not implemented
- account system
- email/push notifications
- payment
- sensitive personal profiling
- causal claims
- black-box recommendation

These require a backend, consent design and additional validation.
