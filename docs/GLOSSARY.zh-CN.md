# 一分钟术语表

| 页面看到的词 | 简单解释 |
|---|---|
| 市场机会 | 未来就业增长和岗位机会综合来看处在什么位置 |
| 工资位置 | 这个职业的中位工资在其他职业中处在什么位置 |
| AI可影响程度 | AI理论上能影响多少职业任务，不等于失业概率 |
| AI实际使用 | 现实中Anthropic系统在这个职业任务上的使用程度 |
| 人的工作结构 | 工作有多依赖判断、人际、责任、情境和具身活动 |
| 未来技能匹配 | 当前技能与WEF所报告未来增长技能的匹配程度 |
| 数据覆盖 | 这个职业需要的核心证据有多少实际可用 |
| SOC6 | 美国详细职业分类 |
| SOC2 | 更宽的职业大类，用于历史趋势背景 |
| Exposure Gap | AI理论可影响程度与现实使用排名之间的差异 |

## 最重要的一句

> **AI可影响程度高，不等于这个职业会消失。**
