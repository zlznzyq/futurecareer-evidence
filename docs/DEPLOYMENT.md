
## Publish

1. Create a **public** repository named `futurecareer-evidence` under `zlznzyq`.
2. Upload/push this repository contents to `main`.
3. Open **Settings → Pages**.
4. Under **Build and deployment → Source**, select **GitHub Actions**.
5. The included Pages workflow deploys the `web/` directory.
6. After the workflow succeeds, add `https://zlznzyq.github.io/futurecareer-evidence/` to the repository **About** section.

GitHub officially supports Pages deployment through GitHub Actions.
