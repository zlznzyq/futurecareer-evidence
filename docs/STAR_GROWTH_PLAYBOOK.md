# Ethical GitHub Star Growth Playbook

The goal is not to game stars. Make the project easy to understand, use and contribute to.

## Launch assets

1. Live GitHub Pages demo.
2. One strong social-preview image.
3. README with the 867-occupation scope and 2–3 real findings above the fold.
4. Reproducibility and data-source links.
5. A clear first issue for contributors.

## Launch message

Lead with the research question, not “please star”.

Suggested hook:

> AI exposure is not the same as career decline. I combined public O*NET, BLS, ILO, Anthropic and historical labor-market data across U.S. occupations to make the evidence inspectable.

Then link to the live demo and repository.

## Good contribution prompts

- challenge an occupation mapping;
- improve a Human Structure proxy;
- add another country;
- reproduce a result;
- improve accessibility or visualization.

Stars should be a consequence of usefulness and credibility.
