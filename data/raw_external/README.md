# External raw inputs

Raw third-party files are intentionally not redistributed here when upstream terms are unclear.

For the public RPLS longitudinal build, download the four occupation **Timeseries** files and place them here using these names:

```text
employment_soc.csv
postings_by_occupation.csv
hiring_and_attrition_by_occupation.csv
salaries_soc.csv
```

Source: https://www.reveliolabs.com/public-labor-statistics

The repository ships the derived SOC2 panel and the exact processing logic, so users can inspect results without re-downloading raw files.
