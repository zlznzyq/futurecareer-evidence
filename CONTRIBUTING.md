# Contributing

Thanks for improving FutureCareer.

Good contributions include:

- correcting an occupation crosswalk;
- improving a Human Structure proxy;
- adding a reproducible data source;
- testing a scoring assumption;
- improving accessibility or visualization;
- adding another country with source-specific methodology.

## Before opening a pull request

1. Explain the problem.
2. Cite the source.
3. Keep raw data separate from transformed data.
4. Add or update a reproducible processing step.
5. Do not describe AI exposure as unemployment probability.
6. Run the relevant validation checks.

For methodological disagreements, open an Issue first.
